# 📚 Système de Gestion de Bibliothèque Universitaire

## 📝 Description
Ce projet est une application logicielle de gestion de bibliothèque universitaire, développée dans le cadre d'un mini-projet axé sur la conception **UML** et la programmation en **Java Avancé**. L'application permet d'automatiser et de simplifier la gestion quotidienne d'une bibliothèque (inventaire, utilisateurs, emprunts).

## 🛠️ Technologies Utilisées
* **Langage de programmation :** Java (Concepts avancés, POO)
* **Conception & Modélisation :** UML (Diagrammes de classes, cas d'utilisation, etc.)
* **Base de données :** SQL (via JDBC)
* **Manipulation de données :** Fichiers CSV

## ✨ Fonctionnalités Principales
* **Gestion du catalogue :** Importation et gestion de la liste des ouvrages à partir du fichier `livres.csv`.
* **Gestion des utilisateurs :** Inscription et suivi des étudiants/professeurs.
* **Gestion des transactions :** Suivi des emprunts, des retours et de la disponibilité des ouvrages.
* **Persistance des données :** Sauvegarde de l'état du système via une base de données relationnelle.

## 📂 Architecture du Dépôt
* 📁 `Projet_Biblio/` : Contient le code source Java de l'application.
* 📁 `UML/` : Regroupe les différents diagrammes de conception modélisant l'architecture du système.
* 📄 `biblio_db.sql` : Script SQL contenant la structure (tables) et potentiellement les données initiales de la base de données.
* 📄 `livres.csv` : Jeu de données utilisé pour charger la bibliothèque initiale.
* 📄 `Système de Gestion...` : Documentation détaillée, rapport ou cahier des charges du projet.

## 🚀 Installation et Exécution

### Prérequis
* Un environnement de développement Java (JDK 8 ou supérieur).
* Un IDE (Eclipse, IntelliJ IDEA, NetBeans).
* Un serveur de base de données (ex: MySQL, PostgreSQL) et le driver JDBC correspondant.
